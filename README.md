# EduTrack

## About the Project
EduTrack is a mobile application developed to help students build and maintain good habits.
The application allows users to track their daily habits, monitor streaks, and receive motivational quotes through an external API.

## Features
* Habit tracking
* Daily streak tracking
* Emoji-based progress monitoring
* Motivational quotes integration
* Local data storage using SQLite

## Technologies Used
* Flutter
* Dart
* SQLite
* REST API
* Android Studio
